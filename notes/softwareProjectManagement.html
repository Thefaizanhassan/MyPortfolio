2What is Project Management?
Definition 1: The art of maximizing the probability that a project delivers its goals on time, to budget, and at required quality.
Definition 2: The application of knowledge, skills, tools, and techniques to project activities to meet project requirements.

7Why Projects Fail & How to Succeed

Why Projects FAIL

📋 Planning Issues

Start coding before understanding; underestimate work; address wrong needs

📝 Requirements Issues

Wrong behavior specified; changing requirements; poor scope management

🔧 Technical Issues

Flawed design; poor code quality; defects found late

👥 People Issues

Poor habits; low accountability; poor testing practices

⚙️ Process Issues

Weak source code control; quality tested only at end; no visibility

How to Make Projects SUCCEED

🔍 Share Information Openly

Transparency is key — share schedules, plans, estimates

✅ Quality from the Start

Not just at the end — review and test everything

🤝 Trust Team Expertise

No artificial hierarchy; use good engineering practices

⚠️ WARNING: Cutting estimation, reviews, requirements gathering, and testing seems faster but causes time loss and lower quality later!

📐 Unit 1C — Software Project Estimation

COCOMO Model · Barry Boehm · Regression-based Formulas

1COCOMO Model
COCOMO = Constructive Cost Model, developed by Barry W. Boehm. Uses a regression-based formula derived from historical project data.
Basic COCOMO

Quick rough estimates. Based on KLOC/SLOC only. Least accurate.

Intermediate COCOMO

Size + 15 Cost Drivers. More accurate than basic.

Detailed COCOMO

Phase-level estimates. Most accurate. Most complex.

Basic COCOMO Formulas

🟢 Organic Mode — Small, simple, familiar
E = 2.4 × (KLOC)^1.05 PM D = 2.5 × (E)^0.38 Months

Small teams, experienced staff, familiar domain

🟡 Semi-detached Mode — Medium size
E = 3.0 × (KLOC)^1.12 PM D = 2.5 × (E)^0.35 Months

Mix of experienced and inexperienced staff

🔴 Embedded Mode — Complex, real-time
E = 3.6 × (KLOC)^1.20 PM D = 2.5 × (E)^0.32 Months

Tight constraints, hardware/software integration

Example Calculation

COCOMO Calculation
Given: Project Size = 10 KLOC, Organic Mode

Effort:    E = 2.4 × (10)^1.05
             = 2.4 × 11.22
             = 26.93 Person-Months

Duration:  D = 2.5 × (26.93)^0.38
             = 2.5 × 3.87
             = 9.67 Months

Team Size: N = E / D
             = 26.93 / 9.67
             ≈ 3 People
💡 Memory Trick

"Once She Explored" → Organic, Semi-detached, Embedded (increasing complexity)

🎯 Exam Tip — Numerical

COCOMO calculations are very frequently asked. Practice with different KLOC values. Remember: higher mode = higher constants = more effort estimate.

5 CBA Evaluation Techniques

💡 Memory Trick

"N P R N I" → Net Profit, Payback period, ROI (Return on investment), NPV (Net present value), IRR (Internal rate of return)

3NPV, ROI, IRR & Payback Period

1. Net Profit

Net Profit Formula
Net Profit = Total Income − Total Expenses

2. Payback Period

Payback Period: The time taken to recover the initial investment.
Payback Period
Payback = Time when Cumulative Returns = Cumulative Costs
YearAnnual BenefitCumulative Benefit
0-₹50,000 (Investment)-₹50,000
1₹15,000-₹35,000
2₹15,000-₹20,000
3₹15,000-₹5,000
4₹15,000+₹10,000 ✅ Payback reached!
✅ Advantages of Payback
  • Simple to calculate
  • Easy comparison
  • Quick assessment
❌ Disadvantages of Payback
  • Ignores benefits AFTER payback
  • Doesn't measure profitability
  • Ignores time value of money

3. Return on Investment (ROI)

ROI Formula — Also called ARR (Accounting Rate of Return)
Average Annual Profit = Net Profit / Total Number of Years ROI = (Average Annual Profit / Total Investment) × 100% Example: Net Profit = ₹50,000 over 5 years, Investment = ₹100,000 Average Annual Profit = 50,000 / 5 = ₹10,000 ROI = (10,000 / 100,000) × 100 = 10%

4. Net Present Value (NPV)

Key Concept — Time Value of Money: Money received TODAY is worth MORE than the same money in the FUTURE. ₹100 today > ₹100 next year.
Discounted Cash Flow (DCF)
Present Value = Future Value / (1 + r)^n Where: r = discount rate (interest rate) n = number of periods into the future As n increases → PV decreases As r increases → PV decreases
YearCash FlowDiscount Factor (10%)Present Value
0-₹50,0001.000-₹50,000
1₹15,0000.909₹13,635
2₹15,0000.826₹12,390
3₹15,0000.751₹11,265

5₹15,0000.621₹9,315
NPV (Sum of all PVs)+₹6,850 ✅
NPV > 0

Project is profitable → PROCEED ✅

NPV < 0

Project loses money → REJECT ❌

NPV = 0

Break even → REVIEW ⚠️

5. Internal Rate of Return (IRR)

IRR: The discount rate that makes NPV = 0. Higher IRR = Better investment. Compare IRR with hurdle rate.
IRR Decision Rule
IRR > Hurdle Rate → Accept project Between two projects: Higher IRR = Better Choice IRR is the rate where: NPV = 0

6Work Breakdown Structure (WBS)
WBS: A hierarchical structure of project activity focusing on the work required to accomplish the project.

PBS vs WBS — Key Difference

📦 PBS — Product Breakdown Structure
  • Hierarchical structure of THINGS
  • Focuses on WHAT will be PRODUCED
  • Deliverables and outputs
  • Example: Patient Module, Billing System
⚙️ WBS — Work Breakdown Structure
  • Hierarchical structure of WORK
  • Focuses on WHAT WORK will be DONE
  • Activities and tasks
  • Example: Design Module, Code Module, Test Module

Types of WBS

Deliverable-Based

Organized by what you deliver. Most common type.

Phase-Based

Organized by project phases (initiation → closure)

Responsibility-Based

Organized by teams or departments

8PERT — Program Evaluation and Review Technique
PERT: Developed by the US Navy (1950s). Uses three time estimates to handle uncertainty in project scheduling.
O — Optimistic

Best case — everything goes perfectly

M — Most Likely

Normal conditions — most probable scenario

P — Pessimistic

Worst case — everything goes wrong

PERT Formulas
Expected Time: te = (O + 4M + P) / 6 Standard Deviation: σ = (P - O) / 6 Variance: σ² = [(P - O) / 6]²
🎯 Exam Tip

The factor 4 in the formula weights the Most Likely estimate more heavily (Beta distribution assumption). Always use te for network calculations.

9CPM — Critical Path Method
CPM: Developed by DuPont (1950s). Uses one deterministic time estimate. Identifies the critical path — the longest path through the network.
CPM Steps
flowchart LR
    A[Draw Network\nDiagram] --> B[Forward Pass\nCalculate ES and EF]
    B --> C[Backward Pass\nCalculate LS and LF]
    C --> D[Calculate Float\nFloat = LS - ES]
    D --> E[Critical Path\nActivities with Float = 0]

CPM Key Terms
ES = Earliest Start time EF = Earliest Finish time = ES + Duration LS = Latest Start time LF = Latest Finish time = LS + Duration Total Float = LS - ES (or LF - EF) Critical Path = Path where Float = 0
