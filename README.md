## 🚀 Installation & Setup

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A code editor (VS Code recommended)
- Live Server extension (optional, for development)

### Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/Thefaizanhassan/MyPortfolio.git
   ```

2. **Navigate to project directory**
   ```bash
   cd MyPortfolio
   ```

3. **Open with Live Server** (VS Code)
   - Right-click on `index.html`
   - Select "Open with Live Server"
   
   OR

4. **Open directly in browser**
   ```bash
   # On macOS
   open index.html
   
   # On Windows
   start index.html
   
   # On Linux
   xdg-open index.html
   ```

5. **View the portfolio**
   - Navigate to `http://localhost:5501` (Live Server)
   - Or directly from the file system

## 🎨 Customization

### Personal Information
Edit `index.html` to update:
- Name and titles
- About section text
- Experience and skills
- Project details
- Contact information

### Styling
Modify `style.css` for:
- Color schemes
- Font families
- Spacing and layout
- Animation timings

### Theme Colors
Adjust these CSS custom properties:
```css
/* Light Mode */
--bg-color: #ffffff;
--text-color: #000000;

/* Dark Mode */
body.dark-mode {
  background-color: #000000;
  color: #ffffff;
}
```

### Adding New Icons
1. Create light version: `icon-name.png`
2. Create dark version: `icon-name_dark.png`
3. Place both in `assets/` folder
4. Add to HTML with both classes:
```html
<img src="./assets/icon-name.png" class="icon icon-light" />
<img src="./assets/icon-name_dark.png" class="icon icon-dark" />
```

### Adding Projects
Copy this structure in the Projects section:
```html
<div class="details-container color-container">
  <div class="article-container">
    <img src="./assets/your-project.png" class="project-img" />
  </div>
  <h2 class="project-title">Your Project Name</h2>
  <div class="btn-container">
    <button class="btn btn-color-2" onclick="location.href='GITHUB_URL'">
      Github
    </button>
  </div>
</div>
```
